# 狸は同じ場所にうんこする

スマートフォンに追加して遊べる縦画面のPWAです。オンライン対戦はルームコードで2人が入室し、ホスト側がゲーム状態を進行します。

## 公開と起動

この `outputs` フォルダーを、Node.js 20以降を使えるHTTPS対応のWebホストに配置します。ホスト側で依存パッケージをインストールして `npm start` を実行してください。ホストが指定する `PORT` 環境変数を使います。

ローカルで起動する場合は、このフォルダーで `npm install` の後に `npm start` を実行し、ブラウザーで `http://localhost:3000` を開きます。スマートフォンから同じWi-Fi経由で確認する場合は、PCのLANアドレスとポート3000を開きます。インターネット対戦とホーム画面への追加には、HTTPSでアクセスできる公開先が必要です。

## スマートフォンに追加

- iPhone：Safariで公開URLを開き、「共有」→「ホーム画面に追加」
- Android：Chromeで公開URLを開き、メニューから「アプリをインストール」または「ホーム画面に追加」

## オンライン対戦

1. 片方が「オンライン対戦を募集」を押し、表示された6文字のルームコードを相手に伝えます。
2. もう片方がコードを入力して参加します。
3. 相手が入室したら、ホスト側が試合を開始します。

現状は2人部屋の試作です。ルーム状態はサーバーのメモリー上に置くため、サーバーを再起動すると開いている部屋は終了します。
